# 软泥守望 · 网页试玩版

一个零依赖横屏玩法原型，支持“自由建造 → 主动开启防守 → 暂停出牌”的核心循环，可直接在浏览器和 GitHub Pages 运行。

在线稳定版：<https://nornttyy.github.io/shilaimutuwei/>

## 运行

```bash
python3 -m http.server 8080
```

然后打开 `http://localhost:8080`。建议使用横屏或桌面浏览器。

## 发布到 GitHub Pages

生成可提交的 Pages 白名单包：

```bash
npm run build:docs
```

构建会同时读取 `assets/asset-spec.json` 和 `assets/rig-parts.json`，并严格检查两份清单引用的 PNG 完整结构；普通素材还会核对尺寸、透明通道和文件体积上限。`asset-spec` 精确声明 74 张普通游戏 PNG；骨骼清单精确引用 8 张角色主图集和 8 张独立表情图集，共 16 张 rig PNG。主图集在运行时裁成身体、眼睛、嘴巴及必要的前后配件骨骼层，眼睛和嘴巴状态则从表情图集独立替换。

`npm run build:docs` 生成的 `docs/` 是 GitHub Pages 白名单包，只包含 `index.html`、`styles.css`、`src/`、两份素材清单，以及清单精确引用的 74 + 16 = 90 张运行时 PNG。校对图、预览图、候选图、独立导出层、源图、旧素材和未被引用的图片不会进入发布包。缺少任何一张清单素材时，构建会列出具体路径并保留上一次成功产物。

构建通过后提交 `docs/` 并推送 `main`，再到仓库的 **Settings → Pages** 配置从 `main` 分支的 `/docs` 目录发布：

1. 将 **Source** 设为 **Deploy from a branch**。
2. 选择 **main /docs** 并保存。

此方案不需要 GitHub Actions 或额外的 workflow 权限。仓库当前使用 **main /docs** 发布；项目内全部使用相对资源路径，可直接运行在 `https://用户名.github.io/仓库名/` 这类子路径。

本地检查发布包时使用：

```bash
npm run build
python3 -m http.server 8080 --directory _site
```

## 渲染与动画

- 公开入口固定加载生成的 PNG 分层骨骼素材；旧的 `?rig=vector` 参数在线上会被忽略，仅本机 `localhost` 调试时可临时启用。启动加载采用 15 秒单图超时、受控并发、一次失败重试和 20 秒前台等待上限，避免全部 90 张图片同时抢占连接或永远卡在加载页；一个角色的所有分层仍然必须完整到齐才会原子切换，分层延迟但生成版立绘已就绪时会优先显示立绘，只有相关图片全部不可用时才使用应急矢量绘制。
- 8 个角色目前共导出 51 个基础部件和 56 个眼睛/嘴巴状态，位于 `assets/generated-v2/rig-parts-exported/`；运行时仍使用图集合批加载，减少网络请求。泡泡的三颗装饰泡已拆成独立骨骼层，并只保留一层位于身体外侧的蓝环；壳壳采用后壳、身体、前壳与表情的稳定遮挡顺序，分层完成度与芽芽、亮钉一致。
- 4 名幸存者和 4 类敌人均已接入部件骨骼动画，覆盖待机、移动、攻击、受击、倒地与死亡状态；酸壳蜗王另有可被打断的蓄力状态。
- 战斗反馈使用逐帧 Canvas 动画：新绘制的命中星芒、冲击环、胶滴、泡泡、叶片、裂隙碎片、蜜胶、换位光团、尘团和彩带从透明 4×4 图集中独立裁切，再分别平移、旋转、缩放和错峰出现；缺图时保留程序化兜底，不使用整张特效图片淡出。每帧最多绘制 64 个图集部件，并为技能与清场保留 16 个高优先级名额；连锁死亡和连续击退会自动简化次要碎片。
- 骨骼定义、动作片段和播放器位于 `src/animation/`，视觉控制器不进入存档数据。

重新生成并检查当前分层素材：

```bash
npm run generate:expressions
npm run export:rig-layers
npm run review:rig
```

动作校对表输出到 `assets/generated-v2/rig-review-current/`，不会进入 Pages 发布包。

## 第一版内容

- 6×6 建造区，左侧软核、右侧怪物入口。
- 无限时建造、手动开波、随时暂停。
- 4 名幸存者、5 种建筑、4 张技能、3 件道具。
- 3 波共 95 名敌人，其中 1 名精英；普通怪以低生命、低伤害、高密度的虫潮形式出现。
- 布局与软晶本地保存。

当前不接正式抽卡、广告、云存档和微信开放能力。核心数据与 Canvas 绘制已分层，后续可以增加微信小游戏运行适配层。
