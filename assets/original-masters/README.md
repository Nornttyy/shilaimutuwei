# Original character masters

This directory is reserved for the exact, full-resolution PNG files approved by
the user. Generated approximations, review sheets, and legacy previews must not
be used as sources here.

Expected source files:

- `survivor-crystal-pin.png`
- `survivor-moss-sprout.png`

The sprout source may contain its original dark vignette; the asset pipeline
will remove that backdrop and retain only genuine transparent alpha. Character
shape, colors, highlights, expression, accessories, and proportions must remain
unchanged.
